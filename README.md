📘 KumarBuildsPro | Interactive 3D Digital Spiral Notebook

A modern, fast, and fully responsive Digital Spiral Notebook Web Application built using HTML5, Tailwind CSS, and Vanilla JavaScript. Experience realistic 3D page-turning animations, automatic note saving, customizable themes, and a smooth writing interface — all in one digital notebook.

✨ Key Features

- 🌀 Realistic 3D Page Turning: Smooth 3D page-flipping animations with a realistic spiral binding design.
- 💾 Automatic Note Saving: Notes are instantly saved using LocalStorage, so your data remains available after refreshing the page.
- 📍 Persistent Page Memory: Automatically remembers your last opened notebook page.
- 🎨 Custom Themes: Multiple beautiful color themes, including Ocean Blue and Soft Pastel, with customizable accent colors.
- ✍️ Customizable Writing Styles: Choose ruled, grid, or blank pages with multiple font styles.
- 📥 TXT Export: Download all your notes as a ".txt" file directly to your device.
- 📱 Touch & Gesture Support: Mobile-friendly swipe navigation and keyboard arrow shortcuts (← / →).
- ⚡ Responsive Design: Optimized for mobile, tablet, and desktop screens.
- 🔄 Persistent Settings: Your selected themes, fonts, page styles, and notebook progress are saved automatically.
